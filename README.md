# **Harshita Data Analytics Portfolio**

A modern and interactive Data Analytics Portfolio built using React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

----

## *🚀Live Portfolio:*  Coming Soon

## **✨Features:**

* Modern futuristic UI
* Responsive design
* Interactive dashboard visuals
* Smooth animations
* Data analytics project showcase
* Skills & experience sections
* Contact integration

----

## **🛠️Tech Stack**

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* Recharts

----

## **📂Sections Included:**

* Hero Section
* About
* Skills
* Projects
* Experience
* Contact

----

## **📦Installation:**

```bash
npm install
npm run dev
```
